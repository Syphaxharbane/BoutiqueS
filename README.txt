BOUTIQUE COMPLETE - TOUS LES FICHIERS A LA RACINE

1) Dans Supabase > SQL Editor, exécute schema.sql.
2) Dans GitHub, mets tous les fichiers de ce ZIP directement à la racine de main.
3) Active GitHub Pages sur main / root.
4) Le compte admin se crée dans Supabase > Authentication > Users.
5) Ouvre /admin.html pour te connecter.
6) Dans Produits, tu peux ajouter photo, nom, prix, catégorie, description et visibilité.
7) Les photos sont envoyées dans le bucket product-images.
8) Les frais de livraison sont actuellement des exemples et sont modifiables dans shop.js, tableau WILAYAS.
IMPORTANT: les règles RLS actuelles donnent les droits d'administration à tout utilisateur authentifié. Pour une vraie boutique publique, il faut ensuite ajouter une vraie gestion de rôles admin.
